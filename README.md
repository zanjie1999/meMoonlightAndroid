# 咩Moonlight

咩咩的魔改Moonlight，基于官方Moonlight，使用官方SunShine

配合IddSampleDriver（注意是i不是L）虚拟显示器驱动，让你的电子垃圾做稳定的60hz的副屏，Spacedesk只能做到最高24hz，并且还伴随着卡顿

### 目前已有功能
1. 开机启动
2. 自动连接指定电脑（没有触摸屏也能连接了）
3. 屏幕关闭自动断开，亮屏自动重连
4. 自定义分辨率
5. 超低的刷新率（给墨水屏用）
6. 增加按物理分辨率裁切成16:9的分辨率，串流的视频中没有一个像素是多余的
7. 多显示器切换，自动切换显示器
8. 全局的返回按钮，电量显示
9. 增加了软件解码器的支持，在没有gpu解码器加速的时候也可以使用，发热大一点总比用不了好
10. 快捷菜单，可以用来给有触摸或者按键输入的设备切换显示器，进行一些快捷操作，按返回键或者菜单键就能显示
11. 降低系统要求到Android4.0，官方只能兼容到4.4
12. 方向键模拟鼠标的功能，方便在电视盒子和按键机上用
13. 展示系统所有编解码器的分辨率刷新率码率等信息
14. MTK解码器优化，比官方更低的解码延迟
15. 音频流畅优先切换功能，减少卡顿
16. USB网络共享下的连接支持
17. 关闭声音，在不需要声音的时候节省带宽
